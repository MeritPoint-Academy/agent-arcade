Coding-level teaching

The agent is small enough to understand.

Each game state becomes four numbers. The policy finds nine nearby human demonstrations, gives closer examples more voting power, and selects LEFT, STAY, or RIGHT.

function predict(state, rows, k = 9) {
  const x = vector(state);
  const near = closest(rows, x).slice(0, k);
  const vote = weightedVote(near);
  return highestVote(vote);
}
