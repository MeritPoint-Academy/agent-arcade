# Third-party notices and research references

Agent Arcade is original software. The following works are cited as research
background or used by the optional open-data extension; their code is not bundled.

## Procgen Benchmark

Cobbe, K., Hesse, C., Hilton, J., & Schulman, J. (2020). “Leveraging Procedural
Generation to Benchmark Reinforcement Learning.” Proceedings of Machine Learning
Research, 119, 2048–2056. <https://proceedings.mlr.press/v119/cobbe20a.html>

## General Video Game AI

The General Video Game AI project is linked as a related open research platform.
<https://github.com/GAIGResearch/GVGAI>

## SkillCraft1 Master Table Dataset

Blair, M., Thompson, J., Henrey, A., & Chen, B. (2013). SkillCraft1 Master Table
Dataset. UCI Machine Learning Repository. DOI: <https://doi.org/10.24432/C5161N>.
Licensed under CC BY 4.0.

The optional analysis downloads the dataset from UCI at run time. Raw player-level
records are not redistributed in this repository.
